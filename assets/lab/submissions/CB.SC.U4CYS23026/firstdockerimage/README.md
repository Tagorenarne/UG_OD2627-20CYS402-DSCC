\# First Docker Image



\## Description



This project uses a minimal BusyBox Linux container image.



\## Docker Image



\* Docker Hub: `mithunns057/firstdockerimage`

\* Base image: `busybox:1.38.0-glibc`



\## Run the Container



```bash

docker pull mithunns057/firstdockerimage:latest

docker run -it --rm mithunns057/firstdockerimage:latest

```

\* `Dockerfile` — Defines the container image.
